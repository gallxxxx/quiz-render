# Видео-викторина «This or That» — подробная инструкция

Короткая памятка лежит рядом с кнопками: **`0 Что делать.txt`**.
Здесь то же самое, но подробнее.

---

## Схема: что за чем идёт

```
   ┌──────────────────────────────────────────────────────────┐
   │  1  ОТКРЫТЬ РЕДАКТОР                                     │
   │     Пишешь вопросы и проценты → Save → закрываешь окно   │
   └───────────────────────────┬──────────────────────────────┘
                               ↓
   ┌──────────────────────────────────────────────────────────┐
   │  2  НАЙТИ ВИДЕО      ← основной путь                     │
   │     Сам качает клипы и подставляет в ролик               │
   │                                                          │
   │  3  НАЙТИ ФОТО       ← если хочется картинки             │
   │  4→5 СВОИ ФАЙЛЫ      ← если есть своё                    │
   └───────────────────────────┬──────────────────────────────┘
                               ↓
   ┌──────────────────────────────────────────────────────────┐
   │  1  ОТКРЫТЬ РЕДАКТОР снова — посмотреть, что вышло       │
   └───────────────────────────┬──────────────────────────────┘
                               ↓
   ┌──────────────────────────────────────────────────────────┐
   │  6  СОБРАТЬ РОЛИК   ← озвучит и соберёт MP4              │
   │     Каждый ролик — свой файл, старые остаются            │
   └───────────────────────────┬──────────────────────────────┘
                               ↓
                  На телефон → залить в TikTok
```

**Главное:** Save в редакторе сохраняет только данные.
Само видео появляется после кнопки 6 — она же его и озвучивает.

---

## Кнопки

### 1 Открыть редактор
Запускает Remotion Studio и открывает браузер на `localhost:3010`.
Там ты видишь ролик целиком, мотаешь ползунком и правишь данные.

Пока чёрное окно открыто — редактор работает. Закрыла окно — выключился.
Если редактор уже запущен, кнопка просто откроет вкладку в браузере.

### 2 Найти видео
Главная кнопка. Берёт подписи из твоих вопросов, ищет на **Pexels**
видеоклипы, готовит их (8 секунд, без звука, нужный размер)
и **сам подставляет в раунды**.

Проверяет, что название места действительно есть в описании клипа —
иначе Pexels подсовывает «просто похожую гору» вместо нужной.

Если клипа для места нет — подставит фотографию и напишет об этом.
Уже скачанное пропускает, поэтому повторный запуск быстрый.

В конце показывает **лист с картинками** — все места ролика одной
страницей, с номерами. Файл «превью картинок» рядом с кнопками;
по этим номерам работает кнопка 2б.

Ключ Pexels уже вписан в файл `ключ pexels.txt`.

### 2б Заменить картинку
Для тех мест, где картинка не понравилась.

Показывает список всего, что стоит в ролике, с номерами — теми же,
что на листе «превью картинок», который делается после кнопок 2 и 3:

```
   Вопрос 1
      1  Ferrari       сверху   ferrari.mp4
      2  Lamborghini   снизу    lamborghini.mp4
```

Называешь номера через пробел («1 7 12») и выбираешь:

- **поискать другую** — скрипт помнит, что уже брал, и возьмёт следующий
  вариант. Можно жать подряд, пока не понравится;
- **поставлю свою** — скажет, как назвать файлы, и откроет «Мои фото».
  Имя — либо как подпись (`Ferrari.jpg`), либо просто номер (`1.jpg`).

В конце лист перерисовывается сам.

### 3 Найти фото
То же самое, но картинками. Источники — Википедия и Openverse.

**Не трогает места, где уже стоит клип.** Так что нажать её после
кнопки 2 безопасно — видео не потеряется.

### 4 Папка для своих файлов
Открывает папку **«Мои фото»**. Туда складываешь свои фотографии
и видеоклипы — хоть сохранённые из браузера, хоть с телефона.

Внутри лежит `ПРОЧТИ МЕНЯ.txt` с подсказкой.

### 5 Добавить свои файлы
Забирает всё из «Моих фото» в ролик: режет в квадрат 1000×1000,
сжимает, разворачивает фото с телефона правильной стороной,
русские названия переводит в латиницу.

**Фокус:** если файл называется так же, как подпись вопроса
(`Big Ben.jpg`, `Times Square.mp4`) — он встанет на своё место **сам**.
Если назван иначе, скрипт напишет, какое имя вписать в поле **image**.

Оригиналы остаются в «Моих фото».

### 6 Собрать ролик
Сначала озвучивает вопросы голосом, потом делает готовый MP4.
Вместе примерно три минуты.
Результат кладётся в папку `Готовые видео`.

Голос выбирается кнопкой 13, там же его можно выключить.

**Каждый ролик сохраняется отдельно** — старые не пропадают.
Имя собирается само из даты и темы выпуска:

```
2026-08-24 23-05 WORLD LANDMARKS.mp4
```

Дата впереди, поэтому папка сортируется сама: сверху старые, снизу свежий.
Если собрать дважды за одну минуту — ко второму добавится `(2)`.

Один ролик весит около 34 МБ. Что уже залила в TikTok — можно удалять руками.

### 7 Текст для озвучки

**Обычно не нужна:** голос ставится сам кнопкой 6. Эта кнопка —
на случай, если захочешь начитать текст своим голосом.
Собирает английский текст всех вопросов в `Готовые видео\озвучка.txt`:

```
IF IT WAS FREE, WHAT WOULD YOU PICK?
Big Ben, or Sydney Opera House?
Taj Mahal, or Colosseum?
...
HOW MANY MATCHED? tell me in the comments. all my best quizzes are on my profile.
```

Копируешь целиком в Higgsfield / ElevenLabs / TikTok и озвучиваешь.

### 8 Добавить озвучку

**Обычно не нужна:** голос ставится сам кнопкой 6. Эта кнопка нужна,
только если ты записала фразы сама.
Берёт голосовые записи из папки **«11 labs»** и раскладывает их по ролику.

**Порядок файлов = порядок в ролике:**

- первый — фраза заставки
- следующие — вопросы, по одному на раунд
- последний — концовка

Сортирует сама по времени в имени файла, так что ничего переименовывать
не надо — просто скачай их подряд. Если один файл скачался дважды,
точный дубль выбрасывается.

Записей должно быть столько же, сколько раундов, плюс заставка и концовка.
Для 9 раундов — 11 файлов. Если не сходится, скрипт скажет об этом.

Фразы расставляются с проверкой «предыдущая договорила», поэтому голос
заставки не перебивает первый вопрос. Концовка растягивается под длину
своей записи — из-за этого ролик может стать чуть длиннее.

**Тонкая настройка** — в файле `src/voice-settings.ts` (эта кнопка его
не трогает, правки сохраняются):

- `VOICE_VOLUME` — громкость голоса
- `VOICE_DELAY_FRAMES` — через сколько кадров после начала раунда вступает голос
- `VOICE_TRIM_START` — сколько секунд отрезать от начала записи
- `VOICE_TRIM_END` — сколько секунд отрезать от конца

Нужен текст для записи — сначала кнопка 7.

### 9 Что уже было
Журнал выпусков: когда собран ролик, какая была тема, какие пары.
Заполняется сам — каждый раз, когда нажимаешь кнопку 6.

Главное в нём — не история, а **проверка на повтор**. Кнопка сверяет
то, что сейчас стоит в редакторе, с прошлыми роликами и показывает:

```
Уже выходило пар: 2 из 9
  Big Ben / Sydney Opera House  →  2026-08-24 23-05 WORLD LANDMARKS.mp4
  Taj Mahal / Colosseum         →  2026-08-24 23-05 WORLD LANDMARKS.mp4

Пара новая, а клип старый:
  Petra (petra.mp4)  →  2026-08-24 23-05 WORLD LANDMARKS.mp4
```

Второй случай — когда место переехало в другую пару, но видео у него
осталось прежним. Тогда стоит перекачать клип: скрипт помнит, какой
брали, и возьмёт следующий.

Кнопка 6 предупреждает о том же самом **до** сборки, чтобы не тратить
минуту на рендер зря. Но не запрещает — если повтор нужен, просто собирай.

Тот же список лежит в `Готовые видео\что уже было.txt`.

### 10 Открыть черновик
Список всех собранных выпусков. Вводишь номер — вопросы этого выпуска
возвращаются в редактор:

```
СОХРАНЁННЫЕ ВЫПУСКИ

  1. FOOD EDITION       (9 вопросов, 2026-08-25 01:17)
  2. DESSERTS EDITION   (9 вопросов, 2026-08-25 01:55)

Введи номер выпуска: _
```

**Зачем это нужно.** Черновик помнит, что было в выпуске, — иначе следующая
тема затирала бы предыдущую. Старый выпуск можно вернуть и пересобрать
затирала бы предыдущую.

Черновики лежат в папке **`Черновики`** рядом с кнопками. В каждой:

- **`озвучка.txt`** — текст, который читает диктор
- **`что это.txt`** — какие вопросы в выпуске и где лежит видео
- `данные.json` — служебный, открывать не надо

### Как озвучить уже собранный выпуск

1. Кнопка **10** — выбрать нужный выпуск
2. Кнопка **6** — собрать заново

Голос запишется сам, начитывать ничего не надо.
Ролик станет чуть длиннее: концовка растягивается под свою фразу.

Если всё-таки хочется своим голосом — это кнопки 7 и 8:
текст, запись на стороне, папка «11 labs», и не забыть её очистить
от прошлых записей.

### 11 Добавить заставки
Переносит нарисованные заставки в проект.

Заставка — это первые две секунды ролика. Обычно она рисуется сама: две
цветные половины, вопрос в рамке и строчка с темой. Но вместо этого можно
подложить свою картинку — с предметами по теме выпуска.

**Как это делается:**

1. Рисуешь картинку в нейросети по своему шаблону — пустая рамка,
   вокруг предметы по теме (еда для еды, пальмы для пляжей)
2. **Без текста!** Наша надпись всё равно ляжет поверх и закроет нарисованную
3. Кладёшь файл в папку **«Обложки»** рядом с кнопками
4. Называешь как выпуск: `11 BEACHES.jpg` — имя можно скопировать
   из папки «Готовые видео»
5. Жмёшь кнопку 11, потом кнопку 6

Заставка встанет сама: картинка станет фоном, текст и строчка с темой
лягут поверх. Своя рамка при этом не рисуется — она уже есть на картинке.

Если файл назван непонятно, кнопка скажет, какой именно.

### 13 Голос диктора
Здесь выбирается голос, которым озвучивается ролик, и здесь же
озвучку можно выключить совсем.

Голос читает три вещи: фразу с заставки, каждый вопрос
(«Ferrari, or Lamborghini?») и концовку. Записывается сам,
когда жмёшь кнопку 6 — бесплатно, ключ не нужен, интернет нужен
только в момент сборки.

Список голосов берётся у самой Microsoft — почти полсотни английских:
американские, британские, австралийские и другие, мужские и женские,
у каждого написан характер.

Послушать можно не собирая ролик: после выбора скрипт предложит записать
пробную фразу. Она ляжет в папку «Голоса» рядом с кнопками.

Пункты можно называть сразу несколько через пробел: «1 2».

Если текст вопросов не менялся, при следующей сборке голос заново
не пишется — берётся готовый. Поменяла подпись — эта фраза
перезапишется сама.

Скорость речи — в файле `настройки.txt` рядом с кнопками:
`СКОРОСТЬ: +15%` быстрее, `-10%` медленнее.

Не было интернета в момент сборки — ролик соберётся молча и скажет
об этом. Просто собери ещё раз, когда связь появится.

## Редактор: где что

Открывается на http://localhost:3010, композиция **ThisOrThat**.

Справа две вкладки: **Schema** и **JSON**. Работай в **Schema** — это форма
с полями. (JSON — то же самое сырым текстом, для программистов.)

Сверху формы — **intro** (заставка):

- **hook** — крупная фраза-крючок, ради которой человек остаётся смотреть
- **edition** — тема выпуска: `WORLD LANDMARKS EDITION`, `FOOD EDITION`, `LUXURY EDITION`

Дальше **rounds** — сами вопросы. У каждого:

- **top** — верхняя половина: `label` (подпись), `image` (имя файла), `color` (цвет)
- **bottom** — нижняя половина, то же самое
- **topPercent** — процент верхней половины. **Нижняя считается сама:**
  поставила 63 — снизу станет 37
- кнопки **+ / −** добавляют и удаляют раунды

Снизу — **outro** (концовка): `title`, `subtitle`, `cta`.

Внизу панели — **Save**. Длительность пересчитывается сама:
добавила раунд — ролик стал на 7 секунд длиннее.

## Откуда берутся материалы

- **Pexels** — основной. Видео и фото, лицензия разрешает коммерческое
  использование и не требует указывать автора
- **Википедия** — точна для достопримечательностей, но требует указания автора.
  Умеет подсунуть логотип вместо фото — такое отсеивается
- **Openverse** — запасной
- **Pinterest и картинки из поиска Google — нельзя**, чужие права

Авторы записываются в `public\photo-credits.txt` и `public\video-credits.txt`.

Где искать самой: **pexels.com**, **pixabay.com**, **unsplash.com** —
бесплатно и без проблем с правами.

Квадратные искать не обязательно — любое фото обрежется по центру.
Выбирай такие, где главное в середине.

## Тайминги

В начале `src/thisorthat-data.ts`:

```ts
export const COUNTDOWN_SECONDS = 5;   // таймер
export const REVEAL_SECONDS = 2;      // показ процентов
export const INTRO_FRAMES = 60;       // заставка (30 кадров = 1 секунда)
export const OUTRO_FRAMES = 150;      // концовка
export const TRANSITION_FRAMES = 15;  // переход между раундами
```

1 раунд = 7 секунд. 9 раундов = ровно 1:05 вместе с заставкой и концовкой.

## Если надо открыть файл с кодом

Файлы `.ts` и `.tsx` — обычные текстовые, просто Windows не знает такое
расширение и по двойному клику ничего не делает.

Правой кнопкой → **Открыть с помощью** → **Блокнот**.

При работе через редактор открывать их не нужно.

## Звук

Три файла в `public/`: `tick.wav` (тик таймера), `reveal.wav` (мягкий
колокольчик), `swoosh.wav` (переход). Все тихие.

Громкость задана в `src/ThisOrThatVideo.tsx` — ищи слово `volume`.
Меньше число — тише. Свои звуки: положи в `public/` файлы с теми же именами.

Фоновой музыки нет намеренно — в TikTok её удобнее накладывать в приложении.
